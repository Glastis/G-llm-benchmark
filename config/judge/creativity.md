## Creativity

This program is also a game: grade a sixth criterion, **Creativity**, out of 10, with the grid below. Here the code is not all that counts. `_judge/shots/` holds three screenshots the game took in its test mode: `roads.png`, a road layout with every shape; `houses.png`, houses with and without a road, and parks; `work.png`, a shop, a factory and a house along one road. Look at them for the looks. Read the code for what they do not show: the selected tool, the preview on hover, a refused placement, the end of the game, and the research and upgrades, where you check that each upgrade does exactly what it shows. When `_judge/shots/` is missing, the game could not take screenshots: judge the looks from the code.
